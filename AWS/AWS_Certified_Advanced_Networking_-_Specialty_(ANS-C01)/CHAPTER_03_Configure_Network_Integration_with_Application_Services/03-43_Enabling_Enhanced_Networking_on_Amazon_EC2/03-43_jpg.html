Slide 03-43-027 — Traditional Virtual Networking

All networking is virtual and controlled by the hypervisor; it shares the same physical hardware.

  • Early passthrough tied a VM to a specific NIC — inflexible.
  • Hypervisor mediation costs CPU and adds latency.

Exam tip: Contrast with enhanced networking (no hardware tie-in, better performance, no extra cost). (AWS Enhanced Networking docs)

Slide 03-43-046 — SR-IOV

Single Root I/O Virtualization supports very high-performance networking requirements.

  • Drastically lower CPU utilization vs. traditional virtual networking.
  • Benefits: higher bandwidth, higher PPS, consistently lower inter-instance latency.
  • No additional charge to enable.

Exam tip: "No additional charge" is a common distractor answer — enhanced networking is free. (AWS Enhanced Networking docs)

Repeat of the SR-IOV benefits slide.

Slide 03-43-048 — Instance support

All current-generation instance types except T2 support enhanced networking.

  • T2 instances do not support enhanced networking.
  • Most modern families (M5/M6, C5/C6, R5/R6, etc.) support ENA.

Exam tip: If enhanced networking is unavailable, check the instance family (T2 excluded). (AWS Instance Types docs)

Slide 03-43-057 — Interface types

Two enhanced networking adapters.

  • ENA: up to 100 Gbps.
  • Intel 82599 VF: up to 10 Gbps.

Exam tip: Speed ceiling is the fastest way to distinguish ENA (100 Gbps) from Intel VF (10 Gbps). (AWS ENA docs)

Slide 03-43-060 — ENA

Elastic Network Adapter (ENA): network speeds up to 100 Gbps for supported instance types.

  • Primary adapter for current-generation instances.
  • Supports higher throughput and PPS than Intel VF.

Exam tip: When you see "100 Gbps" or "current generation", think ENA. (AWS ENA docs)

← PreviousSlide 057Next →Slide 061

Slide 03-43-061 — ENA details

  • Requires ENA module installed and ENA support enabled.
  • Most common implementation for the current generation of instances.
  • ENA Express: high-performance communication between instances in the same subnet.

Exam tip: ENA Express (SRD protocol) reaches up to 25 Gbps instance-to-instance in the same subnet — use for low-latency east-west traffic. (AWS ENA & ENA Express docs)

Slide 03-43-080 — Speed limits

Speed-limit comparison chart between ENA and Intel 82599 VF.

  • ENA: up to 100 Gbps.
  • Intel VF: up to 10 Gbps.

Exam tip: Always pick the adapter whose ceiling meets the stated bandwidth requirement. (AWS Enhanced Networking docs)

Slide 03-43-081 — Intel 82599 VF

Intel 82599 Virtual Function (VF) interface: supports network speeds up to 10 Gbps.

  • Used by older instance families.
  • Lower ceiling than ENA.

Exam tip: 10 Gbps + older families (C3/C4, M4, etc.) → Intel 82599 VF. (AWS Instance Types docs)

Slide 03-43-082 — Intel VF driver & instances

  • Uses the Intel ixgbevf driver.
  • Supported instance types: C3, C4, D2, I2, M4 (excluding m4.16xlarge), R3.

Exam tip: Remember the ixgbevf driver and the m4.16xlarge exclusion for Intel VF. (AWS Instance Types docs)

Slide 03-43-109 — Multi-Flow vs Single-Flow

  • Aggregated instance bandwidth depends on traffic destination.
  • Same-Region: full available bandwidth.
  • Cross-Region, IGW, DX: up to 50% of available bandwidth.
  • Instances with <32 vCPUs: limited to 5 Gbps.
  • Single-flow = 5-tuple (src IP, src port, dst IP, dst port, protocol); limited to 5 Gbps unless in a cluster placement group.
  • Workaround: enable ENA Express for up to 25 Gbps between instances in the same subnet.

Exam tip: Key numbers — 5 Gbps single-flow, 50% for cross-region/IGW/DX, 32 vCPU threshold, cluster placement groups lift the single-flow limit. (AWS Enhanced Networking docs)

Slide 03-43-146 — Conclusion

  • SR-IOV: lower CPU than traditional virtual networking.
  • ENA Express: up to 25 Gbps between instances in the same subnet.
  • ENA: up to 100 Gbps.
  • Intel 82599 VF: up to 10 Gbps.
  • MPTCP offers the full benefits of implementing Enhanced Networking.

Exam tip: MPTCP (Multi-Path TCP) with ENA Express can maximize throughput — a common "best performance" answer. (AWS ENA & ENA Express docs)
